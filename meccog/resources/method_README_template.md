# Method

MecCog Step 1 submission.

- **Team:**

Fill in the six sections below, publish this file as `README.md` at the root of a public repository or archive, and put its URL and the commit SHA on the **Method** sheet of your spreadsheet.

Keep it short. Six honest paragraphs are worth more than six pages. If part of the work was done by hand and part by a model, say which was which rather than describing an idealised pipeline.

---

## 1. Who did the work

A person, an agent, a person and an agent, or several agents working together. Say which steps each did: for example, searching by hand and extracting with a model, or the reverse. Where several agents worked together, name them, say what each was responsible for and how they passed work between them, and say whether a person was involved as well.

## 2. Model and version

The model or models used, with their exact version, and where they ran. One line per agent where several were involved, even if two agents ran the same model. An alias such as "the latest version" is not a version, because it moves. If no model was used, write "none" or "N/A".

## 3. How papers were found

The sources you searched, and the queries or the strategy. Include the searches that returned nothing useful: a search that failed is part of the method.

## 4. How full text was obtained

Which routes you used, in what order, and what proportion of papers you could not reach. This is what lets us tell a difference in access from a difference in extraction when two submissions disagree about the same paper, so it is worth a few concrete sentences.

## 5. What a human checked

How much of the output a person read, and what they were checking for. "A human reviewed every quote against the paper" and "a human skimmed the first ten rows" are both acceptable answers. An unchecked submission is acceptable too, as long as it says so.

## 6. Anything else

Decisions a reader would not guess. Findings you deliberately excluded and why, judgement calls on the hypothesis boundary, known weaknesses in your own submission, anything you would want to know if you were assessing it.
